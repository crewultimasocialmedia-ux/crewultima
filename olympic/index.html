08 Technical Architecture
Stack & Infrastructure

Technical Architecture

🖥️ Frontend
ReactNext.js SSR + SSG · Tailwind CSS · PWA-enabled · Works offline
⚙️ Backend API
Node.jsNestJS · REST + GraphQL · OpenAPI documented · Auto-scaling
⚡ Real-Time
WebSocketsSocket.io · Live scores, results, leaderboards — zero reload
🗄️ Database
PostgreSQL (primary) · Redis (cache + sessions) · Elasticsearch (search)
☁️ Media / CDN
AWS S3Azure Blob · CloudFront CDN · HLS live streaming via AWS IVS
🔑 Auth
OAuth 2.0JWT · SSO · Aadhaar API · Google / Apple Sign-In · 2FA
